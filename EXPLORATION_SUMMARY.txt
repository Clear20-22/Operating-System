================================================================================
                             KEY INSIGHTS
================================================================================

1. PORTABILITY FIRST
   → Use __i32, __u32 instead of int/unsigned int
   → Ensures code works on all architectures

2. INTERRUPT SAFETY
   → splhigh() disables, spl0() enables interrupts
   → Critical for kernel synchronization

3. ABSTRACTION LAYERS
   → VOP_* macros abstract different filesystems
   → VFS layer sits between applications and actual filesystems

4. MIPS ARCHITECTURE
   → Register 29 ($29) is stack pointer
   → lamebus is primary bus (System/161 emulator)

5. THREAD LIFECYCLE
   → S_RUN → S_READY → S_SLEEP → S_ZOMBIE → deleted
   → Zombie state allows exit status retrieval

6. DEVICE NAMING
   → "con:" for non-mountable devices
   → "lhd0raw:" for raw access, "lhd0" for mounting

7. KERNEL INITIALIZATION
   → kmain() calls boot() then menu()
   → boot() initializes all kernel subsystems
